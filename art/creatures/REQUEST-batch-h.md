# Batch H — boss phase and equipment variants

Build roadmap H1–H6 as art/review work. Use approved Batch C painted bosses as
identity references. Generate four nine-cell transparent originals: open-furnace
Heartforged, white-hot Heartforged, seated spear Warlord and standing spear
Warlord. Preserve prompts, originals, repairs and measured registration.

Grounded 256px cells use one scale per sheet, body-centre registration and visible
alpha baseline row 236; retain 12px margins. Seated step slots are reserve weight
shifts, never walking actions. Special/blink cells remain reserves unless the
actual boss pose object supports them. Spears leave an empty release hand;
projectiles, bearers, Emberlings, floor cracks and magical effects stay separate.

Audit the current phase selection (not cumulative): phase-1 standing Warlord can
throw after throne exit or failed bearer spawn; phase 2 has no ranged attack.
Reuse existing Lich body/casting cells for both later phases and existing standing
Warlord cleaver/drum cells for frenzy. Keep gameplay, loader and procedural guards
unchanged until a separate integration step has exact mappings and fallbacks.

Review sources and all exported cells, reproduce exports, and capture supported
poses at 390px and 320px using existing dungeon renderer and warnings. Clearly
label frozen picture substitutions and forced state audits; they are not proofs
of runtime loading, animation timing, every phase transition or offline support.
