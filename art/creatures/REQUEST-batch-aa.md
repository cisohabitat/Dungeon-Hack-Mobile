# Batch AA — wider held weapons, first production tranche

Source/review only; preserve the unpublished Batch Z work and all shipped art.
This tranche paints36 actual CUT frames: Thief/dagger, Fighter/battleaxe,
Cleric/hammer and Fighter/greatsword. First three use one right hand; the sword
uses TWO hands on one elongated grip. All four pairs pass Game.canEquip.
Do not mark the entire AA library complete: flail, sling, throwing knives,
hand crossbow, additional class pairings and named variants still need review.

Nine poses per pair: rest, drawback, windup, strike, cut, sweep, through,
recover, return, at current CUT phases0/.08/.16/.24/.32/.42/.52/.68/.84;
phase1 returns to rest. Draw exact procedural silhouettes and class palettes.
Dagger is short; axe and hammer retain asymmetric heads; sword retains two
connected gauntleted hands and sleeves. Plain ordinary construction, no runes.
Reference grids are native Assets.held frames; held-t1 supplies brushwork only.

Gritty mature monster-compatible realism; true RGBA,3x3 equal square cells,
whole equipment/clean sleeve ends and clear gutters, target8% source padding.
256px exports with measured grips and object-only bounds, uniform family scales,
>=12px registered alpha clearance. Crop/resize/translate/layout only; no pixel
painting, masking, recolouring, mirroring or rotating by export scripts.

Review every source/export and source-proxy captures at390/320, normal/Calm,
all nine phases, recovery, applicable read/drink/cast hand-release stress cases,
160/360/464 buffer rows and exact raw-id/class/pose/two/lit failure guards.
Use real native hand-count selection: two-handed sword releases left grip during
cast/read/drink, so those unsupported single-hand sword cases remain procedural.
No new class abilities, runtime bindings, offline entries or release changes.
Native transition/failure/offline/performance tests remain activation gates.
